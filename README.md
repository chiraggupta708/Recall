# Recall
Coding revision and recall platform.

## What it does

Recall is a personal no-login web app for logging coding, HLD, and LLD questions and revising them with active recall.

- Log question, link, topic, difficulty, answer/code, thinking, correct thinking, and learnings.
- Review due questions by category.
- Type your remembered approach before revealing the saved answer.
- Grade yourself with Again, Hard, Good, or Easy.
- Store data locally in `data/questions.json`.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Checks

```bash
npm test
npm run lint
npm run build
```
